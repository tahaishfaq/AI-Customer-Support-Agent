Slide 1 of 9

Problem

~30 seconds

Do this

Open / or, if already signed in, /dashboard. Do not click around yet.

Say this

Small sites need 24/7 answers (refunds, hours) without a helpdesk team. Hapy is a workspace-scoped support agent: knowledge in, chat out, then insights on what people asked.

Slide 2 of 9

Sign in

~20 seconds

Do this

Open /login. Point at email + password (Google if the button loaded). Mention /register for a new user.

Say this

Customers sign in here. The one admin uses the same /login with email/password. There is no /admin/register. Google cannot sign in as admin.

Slide 3 of 9

Workspace + agent

~40 seconds

Do this

After login, sidebar Workspace (one active). Click + New agent. Fill name, system prompt, welcome. Create agent.

Say this

Everything lives in the active workspace. A second workspace would not list this agent (direct URL → 404).

Slide 4 of 9

Knowledge

~40 seconds

Do this

Agent → Knowledge → Add Text / FAQ. Name: Refunds FAQ. Q: How long do refunds take? A: Refunds are processed within 5 business days. Add knowledge.

Say this

This is what the model may use. PDF upload is optional if Cloudinary is set.

Slide 5 of 9

Studio chat

~50 seconds

Do this

Test tab. In the widget, type the refund question → Send. Then open Conversations.

Say this

Reply should cite the FAQ (5 business days). Inbox shows this agent only — USER + ASSISTANT, not a playground that disappears.

Slide 6 of 9

Analytics

~40 seconds

Do this

Same agent → Analytics, or sidebar Analytics.

Say this

Conversation count, topic, sentiment come from classify. Week 2: chats are stored and labeled.

Slide 7 of 9

Embed + origin lock

~40 seconds

Do this

Customization → Deploy. Point at the snippet (embed.js + data-hapy-key). Copy is enough — do not paste on a random live site unless you own it.

Say this

First load on a new origin locks that site and queues a one-time crawl. A second agent cannot steal that origin.
