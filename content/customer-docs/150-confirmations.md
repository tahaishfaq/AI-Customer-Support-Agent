# Confirmations

When the agent proposes a **WRITE** action (create a repo, update a record, etc.), Aide shows a **Confirm** / **Cancel** card.

## What visitors should do

1. Read the action name and parameters
2. Click **Confirm** only if they agree
3. Wait for the result — success or a clear error

## Important

- Closing the tab does not mean the write was cancelled if Confirm was already pressed
- Cancel stops that pending confirmation
- The AI cannot skip Confirm by wording alone
