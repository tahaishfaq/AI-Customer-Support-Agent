# Upload knowledge

Besides crawling a website, you can add knowledge manually.

## Typical flow

1. Open **Knowledge**
2. Upload supported files or create a text document
3. Give a clear **title** (customers may see it as a source label in studio)
4. Save and wait for indexing to finish before testing

## Tips

- One topic per document when possible
- Update docs when pricing or policies change
- Delete stale documents so the agent does not cite old facts
