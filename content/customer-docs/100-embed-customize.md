# Customize the webchat

Open **Customization** for your agent to set how visitors see the chat.

![Sample: appearance settings and live chat preview](/customer-docs/embed-customize.svg)

## Common settings

- Display name and avatar
- Primary color and theme
- Welcome / intro message
- Placeholder text and footer (“by AIDE” can be hidden on some plans)
- Features such as file upload or message feedback (when enabled)

## Preview

Use the studio preview or Test tab to confirm the look before installing the embed.
