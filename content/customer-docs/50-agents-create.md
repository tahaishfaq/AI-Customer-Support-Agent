# Create an agent

![Sample: New agent form with name, description, and Save](/customer-docs/create-agent.svg)

1. Sign in to Aide
2. Open **Agents** → **New agent** (or equivalent)
3. Give the agent a clear **name** (for example “Help Center” or “Aide Support”)
4. Optionally set a short description and tone
5. Save, then add **knowledge** and customize the webchat

## After create

1. Add knowledge ([overview](/docs/knowledge/overview))
2. Try questions in **Test** ([Test studio](/docs/agents/test-studio))
3. Customize and embed ([install](/docs/embed/install))

## Tips

- Use a name customers will recognize in the chat header
- Disable the agent from the dashboard if you need to pause it safely
