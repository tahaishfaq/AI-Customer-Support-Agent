# FAQ

## Can the agent invent prices or policies?

It should use **your knowledge**. If knowledge is missing, it should say so rather than invent store facts.

## Why must I Confirm some actions?

WRITE tools can change external systems. Confirm keeps humans in control.

## Why can’t I crawl the Aide home URL?

Aide blocks crawling its own app shell. Crawl **`/docs`** (these pages) or your customer website instead. See [Website crawl](/docs/knowledge/website-crawl).

## Why did GitHub stop working after a deploy?

Usually the token expired or encryption/OAuth secrets changed — not because deploy deleted the connection. Reconnect under Tools. See [GitHub MCP](/docs/tools/mcp-github).

## Why are tool toggles disabled?

Agent **Actions** may be off. Turn Actions on, then enable the MCP server and tools.

## Where do customers chat?

On your site via the [embed](/docs/embed/install), or in the [Test studio](/docs/agents/test-studio) for owners.
