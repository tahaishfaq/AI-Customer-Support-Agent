# Install the embed

After customization, install the widget on your site.

![Sample: embed script snippet and site launcher](/customer-docs/embed-install.svg)

## Typical steps

1. Open **Customization** → embed / share section
2. Copy the **script snippet** (includes your agent public key)
3. Paste it before `</body>` on pages where chat should appear
4. Load the site over **https** and confirm the launcher opens

## Checklist

- Public key matches the agent you customized
- Site origin is allowed ([origins](/docs/embed/origins))
- Agent is **enabled**
- Knowledge is indexed if you expect grounded answers
