# Agents overview

Each **agent** is a separate support bot with its own knowledge, customization, and tools.

![Sample: Agents list with Enabled status](/customer-docs/agents-list.svg)

## Studio tabs (typical)

- **Overview** — name, status, quick links
- **Knowledge** — uploads and website crawl
- **Test** — chat as a visitor and inspect tool activity
- **Customization** — webchat look, embed, tools/actions
- **Share / conversations** — depending on your build

## Best practices

- One agent per product or brand voice when possible
- Keep instructions short; put facts in **knowledge**
- Test tool writes with Confirm before going live
