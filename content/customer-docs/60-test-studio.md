# Test studio

The **Test** tab lets you chat like a logged-in or guest customer without installing the embed.

![Sample: Test studio chat with Learn more link](/customer-docs/test-studio.svg)

## What you can check

- Answers from knowledge titles and sources
- Tool calls (including Confirm for write actions)
- GitHub / MCP connection warnings
- Identity toggle: **Logged-in customer** vs guest (when enabled)

## Tips

- Prefer production-like knowledge before judging quality
- For GitHub MCP, connect and test on the **same environment** where OAuth is configured (usually production)
- If Actions are off for the agent, tools will not run — turn **Actions** on under Tools
